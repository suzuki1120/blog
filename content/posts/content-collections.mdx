Cloudflare Workers ではリクエスト時にファイルシステムを読めません。そのため、記事はビルド時にデータへ変換しておく必要があります。

`content-collections` を使うと、frontmatter を zod で検証したうえで、通常の `import` で記事一覧を取得できます。

```ts
import { allPosts } from "content-collections";

const latest = allPosts.toSorted((a, b) => b.date.localeCompare(a.date))[0];
```

必須項目の漏れや日付の書式ミスはビルド時にエラーになるため、公開後に気付くことがなくなります。
